Entry for the [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) bounty on [make.fun](https://make.fun) — one line, 120 characters at most: the funniest voicemail greeting a cat would record.

## The greeting

> Hi, it's Miso. I'm knocking your mug off the table. Leave a message — I'll ignore it and wake you at 4 a.m. for food.

(117 characters — inside the 120-character gate.)

## Why this line

- **It is a voicemail greeting, in the cat's own voice.** First person, a named cat (Miso), a "leave a message" — not an owner describing a cat.
- **The joke is specific to cats, three times over.** Knocking things off tables, ignoring everyone, and demanding food at 4 a.m. — the judge brief's own examples, stacked into one line.
- **The punch lands fast.** It reads naturally spoken aloud in the few seconds a caller waits, with the payoff in the last clause.
- **No tired pun.** No "purr-fect", no "meow after the beep" — the humour comes from the cat's attitude, not a catchphrase.

## How it works

`main.ts` writes the greeting to `/output/entry.txt`, exactly as the competition requires. Run it with Node 22.18+:

```sh
node main.ts
cat /output/entry.txt
```
